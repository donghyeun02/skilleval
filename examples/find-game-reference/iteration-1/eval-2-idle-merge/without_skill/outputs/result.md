# 합성(Merge) & 방치형(Idle) 게임 글로벌 레퍼런스 조사 (2025-2026)

## 개요

합성 게임과 방치형 게임은 2025~2026년 글로벌 모바일 게임 시장에서 가장 빠르게 성장 중인 장르입니다. 합성 게임 시장은 "단순 서브장르"에서 글로벌 매출 핵심 엔진으로 자리잡았으며, 방치형 게임 시장은 2024년 기준 25억 달러 규모에서 2033년 61억 달러까지 성장 예상(CAGR 10.8%)입니다.

---

## 합성(Merge) 게임 레퍼런스

### 1. Gossip Harbor: Merge & Story (Microfun)
- **장르**: 합성-2 + 내러티브 드라마
- **출시**: 2022년 (성장 폭발: 2024~2025)
- **매출 성과**:
  - 2025년 연간 매출 약 6억 5천만 달러 (Gardenscapes 추월, 합성 장르 1위)
  - 2026년 3월 월 매출 1억 4,410만 달러 (역대 최고)
  - 누적 매출 6억 7,700만 달러 이상
- **핵심 설계 특징**:
  - **스토리 통합 메타**: 아버지의 레스토랑 재건을 주제로 한 서사와 합성 게임플레이가 유기적으로 결합
  - **인테리어 커스터마이징**: 플레이어가 업그레이드 외관을 직접 선택 가능 → 자기표현 욕구 충족
  - **즉각적인 라이브옵스 노출**: 게임 초반부터 이벤트, 시간제한 오퍼 등 라이브옵스 요소 적극 노출
  - **합리적 수익화**: 소액 결제는 경쟁사보다 저렴하게, 고액 결제는 더 높게 설정 → 폭넓은 과금 유도
  - **타겟 유저**: 여성 플레이어 약 80%
- **참고 링크**: [Gossip Harbor 성공 분석 (Udonis)](https://www.blog.udonis.co/mobile-marketing/mobile-games/gossip-harbor), [Deconstructor of Fun 분석](https://www.deconstructoroffun.com/blog/2024/8/19/finding-genre-success-the-case-of-gossip-harbor)

### 2. Travel Town (Magmatic Games)
- **장르**: 합성-2 + 타운빌딩
- **매출 성과**:
  - 2026년 초 기준 월 매출 약 4,500만 달러
  - 광고 수익 포함 시 약 1억 달러 돌파
  - 출시 초기 대비 매출 393% 성장
- **핵심 설계 특징**:
  - **심플한 코어 루프**: 합성-2 메카닉에 집중, 복잡한 메타시스템 최소화
  - **에너지 시스템 최적화**: 세션 시간 연장 없이 에너지 소비량 2배 설계 → 과금 전환율 극대화
  - **균형잡힌 경제**: 보관함 과금 의존도를 낮추고 자연스러운 소비 유도
  - **데이터 기반 UA**: Google AdMob 74%, Facebook 13% 비중의 광고 네트워크 활용
- **참고 링크**: [Travel Town 성공 요인 분석 (Naavik)](https://naavik.co/digest/why-travel-town-is-dominating-mobile-merge/), [FoxAdvert 분석](https://foxadvert.com/en/digital-marketing-blog/the-secrets-of-mobile-merge-mastery-learn-from-travel-towns-success/)

### 3. Merge Mansion (Metacore)
- **장르**: 합성 + 미스터리 퍼즐 + 스토리
- **매출 성과**:
  - 누적 매출 7억 6,060만 달러
  - 누적 다운로드 6,300만 회 이상
  - 2024년 매출 1억 5,400만 유로, 영업이익 1,870만 유로 달성 (흑자 전환)
- **핵심 설계 특징**:
  - **미스터리 내러티브**: 주인공 Maddie와 수수께끼의 할머니 Ursula를 중심으로 한 스토리
  - **라이브 이벤트 전략**: 2024~2025년 사이 라이브 이벤트 횟수 2배 증가
  - **배틀패스 시스템**: 핵심 매출 드라이버
  - **혁신적 이벤트 타입**: 코인 이벤트, 데코 이벤트, 오더 이벤트 등 다양한 이벤트 설계
- **참고 링크**: [Merge Mansion 라이브 이벤트 전략 (Liftoff)](https://liftoff.ai/blog/metacore-merge-mansion-live-event-strategy/)

### 4. Tasty Travels: Merge Game (Century Games)
- **장르**: 합성 + 요리 + 도시 건설
- **출시**: 2024년 4월
- **매출 성과**: 2026년 3월 기준 월 2,930만 달러 (합성 장르 세계 2위)
- **핵심 설계 특징**:
  - **글로벌 요리 테마**: 500가지 이상의 고유 재료와 요리 방식 → 문화적 다양성 어필
  - **스토리 모드**: 블로거 지망생 소녀의 세계 음식 탐험 서사
  - **소셜 기능**: 친구와 레시피 교환, 가상 쿠킹 파티 등 커뮤니티 요소
  - **하이브리드 아트 스타일**: 반사실주의 + 반만화풍 혼합 그래픽
- **참고 링크**: [Tasty Travels 공식 사이트](https://www.centurygames.com/games/tasty-travels/)

## 방치형(Idle/AFK) 게임 레퍼런스

### 5. AFK Journey (Lilith Games / Farlight Games)
- **장르**: 방치형 RPG + 오픈월드
- **매출 성과**:
  - 출시 6개월 만에 누적 1억 5,830만 달러
  - 2025년 5월 글로벌 매출 전월 대비 +66.2% 급성장
  - 월간 활성 유저(MAU) 약 130만 명 (2025년 기준)
- **핵심 설계 특징**:
  - **AFK Arena의 진화 버전**: 기존 팬층을 유지하면서 신규 유저에게도 어필하는 밸런스
  - **오픈월드 탐험**: 방치형 RPG에 오픈월드 요소를 도입한 혁신
  - **고품질 아트**: 스튜디오 지브리 풍의 아트 스타일
  - **가챠 + 컬렉션**: 히어로 수집 메카닉과 사회적 자랑 요소 결합
- **참고 링크**: [AFK Journey 수익 분석 (MAF)](https://maf.ad/en/blog/afk-journey-analysis/), [Naavik 분석](https://naavik.co/digest/lessons-learned-from-afk-journey/)

## 시장 트렌드 요약

| 항목 | 내용 |
|------|------|
| 합성 게임 시장 규모 | 2025~2026년 급격히 성장, 글로벌 모바일 매출 상위 장르로 부상 |
| 방치형 게임 시장 | 2024년 25억 달러 → 2033년 61억 달러 예상 (CAGR 10.8%) |
| 주요 수익화 방식 | 에너지 시스템, 배틀패스, 라이브 이벤트, 인앱 결제 |
| 핵심 성공 요소 | 스토리 통합, 라이브옵스, 커스터마이징, 소셜 기능 |
| 주요 타겟층 | 합성 게임: 25~45세 여성 / 방치형 RPG: 코어~미드코어 남녀 혼합 |
| 유행 트렌드 | 내러티브 + 합성, 오픈월드 + 방치형, 글로벌 문화 테마 |

## 기획 시 참고 포인트

**합성 게임 기획이라면:**
- 단순한 merge-2 코어에 **스토리/내러티브 메타** 추가가 필수 트렌드
- **커스터마이징 요소** (인테리어, 캐릭터 외형 등)로 플레이어 자기표현 욕구 충족
- **라이브 이벤트를 초반부터** 설계에 포함할 것
- 여성 유저 타겟팅 시 Gossip Harbor, 중성적 타겟 시 Travel Town/Merge Mansion 참고

**방치형 게임 기획이라면:**
- AFK Journey처럼 **기존 방치형 공식에 신선한 요소**(오픈월드, 고품질 비주얼) 추가
- 자동 전투 + **소셜/길드 시스템** 결합으로 장기 리텐션 확보
- 가챠 수집 메카닉은 방치형 RPG의 핵심 매출원
