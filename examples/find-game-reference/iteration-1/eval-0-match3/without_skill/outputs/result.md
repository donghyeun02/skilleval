# 모바일 캐주얼 매치3 퍼즐 게임 레퍼런스 추천

data.ai 접근 없이 공개 정보 기반으로 모바일 캐주얼 매치3 게임을 개발할 때 참고할 수 있는 레퍼런스를 정리했습니다.

---

## 1순위 레퍼런스: Candy Crush Saga (King)

당신이 이미 언급한 게임이지만, 여전히 매치3 장르의 가장 중요한 레퍼런스입니다.

**왜 참고해야 하는가:**
- App Store/Google Play 퍼즐 카테고리 최장기 톱 차트 유지
- 캐주얼 매치3의 사실상 표준 UX/UI 패턴 정립
- 레벨 디자인 패턴(장애물, 목표 다양성)이 풍부
- 메타게임(보스터, 이벤트, 진행 맵) 구조가 잘 정립됨

**분석 포인트:**
- 레벨 목표 유형 (젤리 클리어, 재료 내리기, 점수 달성 등)
- 난이도 곡선 (25레벨, 50레벨 등 허들 설계)
- 부스터 시스템과 화폐 설계
- 진행 맵(사가 맵) 구조

## 2순위 레퍼런스들

### Royal Match (Dream Games)
- 2021년 이후 Candy Crush를 위협하는 최대 경쟁작
- 더 심플하고 직관적인 UI/UX — 현대적 캐주얼 기준
- 왕국 꾸미기 메타(디코레이션 메타)가 핵심 리텐션 루프
- **핵심 차별점:** King의 복잡한 UI보다 훨씬 깔끔한 레이아웃
- 신규 개발 시 가장 현실적인 현대 표준

### Toon Blast (Peak Games / Zynga)
- 블록 팝 방식 (매치2+ 인접 블록) — 엄밀히 스와이프 매치3와 다름
- 캐릭터/코믹 스타일 IP 활용 방식 참고
- 클랜/팀 시스템 소셜 구조 참고
- **참고 포인트:** 소셜 기능과 라이브옵스 이벤트 구조

### Gardenscapes / Homescapes (Playrix)
- 스토리+매치3 결합 포맷의 대표작
- "하트" 라이프 시스템과 광고 수익화 균형
- 메타 레이어(정원/집 복원 스토리)가 리텐션의 핵심
- **참고 포인트:** 내러티브를 활용한 리텐션 루프

### Merge Mansion / Project Makeover (Metacore / Magic Tavern)
- 더 넓은 메타게임 + 매치3 조합
- 인스타그램 광고 전략으로 화제가 된 타이틀
- 타겟 오디언스(여성 25~45) 캐주얼 UX 참고

## 레퍼런스 분석 프레임워크 (data.ai 없이 하는 방법)

data.ai 없이도 다음 방법으로 충분한 인사이트를 얻을 수 있습니다:

### 1. 앱스토어 직접 분석
- **App Store / Google Play 퍼즐 카테고리 차트** 직접 확인
- 리뷰 분석: 1~2점 리뷰에서 유저 페인포인트 파악
- "사람들이 함께 구매한 앱" 섹션으로 경쟁 지형 파악

### 2. 유튜브 게임플레이 영상
- "Candy Crush level 100" 같은 검색으로 레벨 디자인 직접 관찰
- "Royal Match gameplay" 로 현재 UX 트렌드 분석
- 유저 반응 댓글에서 선호/불만 포인트 파악

### 3. 커뮤니티 리서치
- Reddit r/CandyCrush, r/mobilegaming
- Discord 게이밍 커뮤니티
- 유저 불만 = 개선 기회 파악

### 4. 공개 인터뷰 & GDC 발표자료
- GDC Vault에서 "match-3 design" 검색 (일부 무료)
- King, Dream Games, Playrix 개발자 인터뷰 검색

## 핵심 권장사항

1. **Royal Match를 메인 레퍼런스로** — 2024~2025년 기준 가장 최신 캐주얼 표준
2. **Candy Crush는 레벨 디자인 교과서로** — 장르의 기본기를 배울 수 있는 가장 데이터 풍부한 타이틀
3. **두 게임을 직접 50레벨 이상 플레이** — 직접 경험이 가장 정확한 리서치
4. **1~2점 리뷰를 집중 분석** — 경쟁작의 약점이 곧 차별화 기회

캐주얼 타겟이라면 특히 Royal Match의 "진입장벽 낮은 첫 10레벨 설계"와 "왕국 꾸미기 메타"를 집중적으로 분석하는 것을 추천합니다.
