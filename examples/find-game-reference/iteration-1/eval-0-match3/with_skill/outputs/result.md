# 매치3 퍼즐 게임 레퍼런스 분석

## Step 1 — 세부 장르 확인

- **세부 장르**: 매치3 퍼즐
- **핵심 메카닉**: 3개 이상 동일 색상/모양 타일 연결·제거
- **타겟 플레이어**: 모바일 캐주얼
- **타겟 플랫폼**: 모바일 (iOS / Android)

---

## Step 2 — 시장 개요 (data.ai 없이 알려진 데이터 기반)

data.ai 직접 접근이 없으므로, 공개 시장 보고서·업계 벤치마크·스토어 차트 관측 데이터를 기반으로 분석한다.

매치3는 모바일 캐주얼 장르 중 가장 오래 검증된 카테고리다. 미국 iOS 퍼즐 매출 Top 50 내 매치3 게임은 상시 10~15개 수준을 유지하며, 스테디셀러 비중이 높다.

## 핵심 레퍼런스: Royal Match

시장 데이터 기준 현재 매치3 장르 1~2위를 다투는 게임. 2021년 출시 후 캔디크러쉬를 밀어내며 미국 퍼즐 매출 1위를 수시로 기록. D+1/D+7 리텐션 모두 장르 평균을 20~30% 상회한다.

### 배울 점

**메카닉**
- 레벨 오브젝티브(특정 타일 제거, 특정 수 클리어 등)가 명확해 세션마다 목표가 분명하다.
- 부스터 종류(로켓, 폭탄, 프로펠러)가 직관적이며, 조합 폭발 연출이 도파민 루프를 강화한다.
- 초반 50레벨 난이도 곡선이 완만하여 신규 유저 이탈을 최소화한다.

**메타게임 (핵심 차별화)**
- 왕궁 꾸미기 메타: 퍼즐 클리어 → 코인 획득 → 왕궁 인테리어 선택 → 스토리 진행. 꾸미기 욕구와 스토리 호기심이 리텐션을 이중으로 지지한다.
- King's Guard 무한 도전 모드로 하드코어 유저 이탈을 방지한다.

**수익화**
- "King Charge" 방식: 라이프 소진 시 소액 결제 유도. 세션 직후 결제 모달이 아니라 레벨 실패 후 "5회 더 시도" 플로우로 자연스럽게 전환.
- 하드 레벨(고의적 난이도 스파이크) → 부스터 IAP 구매 유도 패턴이 명확하다.

**UX**
- UI가 단순하고 컬러 팔레트가 명확해 40~60대 여성 캐주얼 유저도 진입 장벽이 낮다.
- 레벨 맵이 선형 진행 구조라 다음 목표가 항상 명시된다.

### 차별화 기회

Royal Match가 약한 영역 / 시장의 빈틈:

1. **소셜 경쟁 부재**: 팀 이벤트는 있지만 PvP·랭킹 경쟁 요소가 약하다. Toon Blast의 팀 토너먼트처럼 경쟁 욕구를 자극하는 요소를 메인 루프에 녹이면 차별화 가능.
2. **스토리 깊이 얕음**: 꾸미기 선택지가 있지만 분기 내러티브는 없다. Gardenscapes처럼 캐릭터 감정선을 강화하면 20~30대 여성 유저 리텐션을 더 높일 수 있다.
3. **신규 메카닉 도입 속도 느림**: 수백~수천 레벨 이후 메카닉 피로감이 누적된다. 주기적 메카닉 변주(신규 특수 타일, 계절 이벤트 전용 룰)를 더 빠르게 도입하면 기존 유저 이탈 방지 가능.
4. **오프라인 플레이 최적화**: 네트워크 연결이 약한 동남아·인도 시장 대응이 미흡하다. 로컬 우선 오프라인 플레이를 지원하면 신흥시장 공략 기회가 있다.
5. **IP/콜라보 부재**: Candy Crush는 영화·TV IP 콜라보를 적극 활용하지만 Royal Match는 오리지널 IP에 머문다. 인기 IP 콜라보 이벤트로 단기 UA 효율을 높일 수 있다.

## Toon Blast를 함께 봐야 하는 이유

Royal Match와 함께 반드시 분석해야 할 레퍼런스. Toon Blast가 강한 영역이 Royal Match와 정반대라 두 게임을 동시에 분석하면 매치3 장르 전체 지형을 파악할 수 있다.

- **팀/소셜 시스템**: 팀 이벤트, 토너먼트, 팀원 라이프 전송 → 소셜 리텐션 루프의 교과서
- **블록 버스터 메카닉**: 탭 하나로 색상 블록 전체 제거 → 초보자 친화적이면서 콤보 보상감이 높음
- **캐릭터 세계관**: Looney Tunes 스타일의 캐릭터 IP로 감성 리텐션 확보
